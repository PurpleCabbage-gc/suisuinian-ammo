# 碎碎念弹药库

> 把「我有东西想说」变成「原来我也可以讲」

一个面向小红书内容创作者的 AI 创作工作流（FemAI vol.3 Demo Day 项目）。备选名「今天发什么」。

## 它做什么

- **素材系统**：把你的日志、灵感便签、定位卡沉淀成弹药
- **选题系统**：AI 从你的真实记录里发现观点、裂变痛点，配合手动去小红书验证
- **内容系统**：分框架口喷 → AI 出完整草稿 → 引用提问多轮修改，一键替换

## 技术

- 纯静态单文件 `index.html`，无构建步骤，GitHub Pages 直接部署
- 支持多家 OpenAI 兼容模型（DeepSeek / GLM / Kimi / 通义千问 / 豆包 / OpenAI / 硅基流动），BYOK 自带 Key
- 未配置 Key 时运行在演示模式（内置真实链路样本）

## 隐私

- 你的所有内容与 API Key 只存在你自己的浏览器本地（localStorage），本项目无服务器、不保存任何数据。
- 唯一例外：主动接入 AI 时，本次输入会发送给你自己选的服务商用于生成，仅在你填写 API Key 后发生。
