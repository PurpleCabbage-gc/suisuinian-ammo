AI 在这里的位置

AI 干四种活：裂变痛点、评估素材、搭框架、给修改建议。
但每个 AI 产出都带 草 稿 角标——最后一稿的品位，永远是人。

你的数据只在你手里

日志、灵感、定位卡、风格卡、我的经验库，以及你填的 API Key，全部只存在你自己的浏览器本地（localStorage）。本产品没有服务器、不保存你的任何数据。唯一例外：当你主动接入 AI 时，本次输入会发送给你自己选的服务商（DeepSeek / GLM 等）去生成结果——这也只在你填了 API Key 之后才会发生。
